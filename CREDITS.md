# Credits and provenance

Based on Charles Swires' Saturn/Galaxian Java projects.

- `SaturnExplosion.java`: Charles Swires' original 200-particle Saturn algorithm,
  adapted to time-based updates, 3-pixel particles and the later 2x fade rate.
- `SoundEffects.java`: retained from the current Galaxian project, with the audio
  thread and diagnostic heading renamed to Scramble.
- `HighScores.java`: retained from the current Galaxian project, using a separate
  `scramble-scores.bin` file.
- Scrolling terrain, side-scrolling model, ships/targets, bombs, fuel system and
  flight UI: newly implemented for this project.

All visuals are drawn in Java. No third-party sprite pack, original arcade
assets, ROMs or sound recordings are included. No generative image assets are
required. The sound effects are synthesized in Java.

Scramble is associated with Konami's arcade game. This is an independent inspired
project, not an official game, exact level reproduction or emulator.
